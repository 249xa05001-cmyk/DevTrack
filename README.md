  # 🚀 DevTrack – Developer Progress Tracker

DevTrack is a modern and responsive web application designed to help developers manage learning goals, track progress, maintain coding streaks, and improve productivity through an interactive dashboard.

---

## ✨ Features

- 🎯 Add, Edit & Delete Learning Goals
- ✅ Mark Goals as Completed
- 🔍 Search, Filter & Sort Goals
- 📊 Interactive Analytics Dashboard
- 📈 Goal Progress Tracking
- 🍩 Charts using Chart.js
- 📝 Daily Notes with Auto Save
- 🔥 Daily Coding Streak Tracker
- 🌙 Dark & Light Mode
- 🔔 Browser Notifications
- 📤 Export & Import Goals (JSON)
- 💾 Local Storage Support
- 📱 Fully Responsive Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- LocalStorage API
